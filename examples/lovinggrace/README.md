# «Машины благодатной любви» — вертикальный ролик 9:16

По эссе Дарио Амодеи *Machines of Loving Grace: How AI Could Transform the World for the Better* (Anthropic, октябрь 2024).
Оригинал: https://darioamodei.com/machines-of-loving-grace — пересказ на русском в пяти главах: «Не магия», «Тело и разум», «Для всех?», «Демократия», «Смысл».

## Что в файле
- `lovinggrace_9x16.mp4` — 1080×1920, 30 fps, 3:52 (6965 кадров), H.264 + AAC, русская озвучка (edge-tts, голос ru-RU-Dmitry, +5 % скорость), субтитры вшиты в картинку.
- Вся графика нарисована кодом (Remotion/React), без стоковых картинок и шрифтовых лицензий, требующих упоминания.
- Музыки нет намеренно (см. «Права»).

## Как проверялось
- Три полных рендера (v1 → v2 → v3), после каждого — независимый QC по главам: пять агентов-инспекторов проверяли каждый кадр по чек-листу (границы контента, кегли ≥32 px для подписей, синхрон субтитров ±3 кадра с озвучкой, стыки между шотами, факты и числа строго по эссе, один glitch-элемент на шот).
- QC v1: 3 высоких / 24 средних / 43 низких → волна фиксов по 8 группам шотов.
- QC v2: 0 высоких / 9 средних / 34 низких; все средние закрыты (наложение карточек глав на последний кадр шота, скачок сцены на 60 px в главе 4, подпись поперёк мозга в главе 2, капсула у HUD в главе 3, ужатый титр) и ещё 7 низких (выходы за правую границу/низ после наездов камеры).
- v3: стыки, карточки глав, титр и исправленные шоты просмотрены глазами по кадрам (контакт-листы), длительность и число кадров сверены с таймлайном.

## Известные ограничения (низкие, оставлены)
- В нескольких шотах герой чуть меньше нормы 260 px (SC26 253, SC29 189, SC34 239) — компоновка вертикали.
- Крест «не чат» (SC07) и «?» (SC45) входят на 0.9–1.1 с позже начала фразы — так задуман такт (сначала пузыри/призрак).
- HUD-капсула пуста 4 кадра на морфе между главами 3 (f_4251–4254).
- Первый кадр некоторых шотов почти пустой (draw-on начинается с 0) — один кадр, на 30 fps не читается.

## Права
- Текст — пересказ эссе своими словами; в титре указан источник и автор. Для коммерческой публикации стоит перепроверить допустимость пересказа (эссе опубликовано автором открыто, но без явной лицензии).
- Музыки нет. Можно подмешать трек скриптом `scripts/music_mix.sh <in.mp4> <music> <out.mp4>` (−31 LUFS, дакинг под голос) — трек и права на него выбирает владелец; в прошлом ролике использовался защищённый авторским правом трек, для публикации это риск.
- Голос — Microsoft edge-tts (бесплатный нейросетевой синтез); условия использования Microsoft для коммерческих публикаций — на владельце.
