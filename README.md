**Русский**

**Тема на входе — готовое объясняющее видео на выходе.** Kettu-Shortmaster — это скилл для [Claude Code](https://claude.com/claude-code) / [Codex](https://openai.com/codex), который превращает любую тему в motion-graphics ролик на чёрном фоне: закадровая озвучка (TTS), субтитры, карточки глав, верхний HUD и нижний прогресс-бар по главам. Каждый кадр отрисован кодом на [Remotion](https://remotion.dev) (React + TypeScript). Без стоковых видео, без генеративных видеомоделей, без чужих кадров.

Это не CLI. Здесь лежит весь метод, который нужен агенту, чтобы довести фильм до конца: компилируемый шаблон Remotion, библиотека примитивов и света, инструменты для озвучки / раскадровки / рендера / количественного QC, письменные спецификации стиля и движения, протокол разделения труда между агентами и готовый образец качества.

## Наши ролики (образцы)

Оба сняты этим же пайплайном, озвучка и графика — кодом, русская речь:

- **«Машины благодатной любви»** — вертикаль 9:16 (1080×1920), 3:52, по эссе Дарио Амодеи *Machines of Loving Grace*. Озвучка edge-tts `ru-RU-DmitryNeural`. → [`examples/lovinggrace/`](examples/lovinggrace/)
- **«Вирусы разума»** — 1280×720, 3:54. → [`examples/mind-viruses/`](examples/mind-viruses/)

## Что делает

- **Вход**: тема («объясни векторные базы данных») или статья/документ, который нужно превратить в видео. Вы также задаёте длительность и язык.
- **Выход**: MP4 H.264 с синхронной озвучкой, субтитрами по границам слов, карточками глав, HUD и прогресс-баром; плюс полный «бумажный след» — исследование с источниками, текст озвучки, раскадровка, код каждого шота, отчёты QC.
- **Как**: агент исследует тему с источниками, пишет текст, генерирует озвучку и покадровый таймлайн, делает раскадровку, затем раздаёт параллельным агентам-сборщикам по одному компоненту Remotion на шот. Агенты QC проверяют отрендеренные кадры по критериям перед сдачей.
- **Время**: примерно 1–3 часа (зависит от длительности), большую часть агенты собирают шоты параллельно. Вас спрашивают ровно на четырёх контрольных точках.

## Спецификация вывода

| | |
|---|---|
| Кадр / частота | 1280×720 @ 30 fps, H.264 |
| Длительность | по вашему выбору (см. таблицу); 2–8 минут работают |
| Язык | китайский, английский или русский (`lang` в `src/config.ts`); с ним переключаются типографика, бюджеты субтитров и TTS |
| Вид | чёрный холст с одним из двух фонов — звёздное поле с туманом или точечная волна (`bg` в `src/config.ts`); белая линейная графика + фиолетовые акценты; сверхжирные заголовки |
| Постоянные слои | субтитры 44 px белые с чёрной обводкой, нижний прогресс-бар по главам, верхний HUD-капсулы, опциональная «труба» шагов, подпись в конце `built by Kettu-Shortmaster skill` (`builtBy`, `''` чтобы убрать) |
| Озвучка | китайский: edge-tts `zh-CN-YunxiNeural`. английский: kokoro-82m `am_liam`. русский: edge-tts `ru-RU-DmitryNeural` (границы слов → точные субтитры). Либо свой TTS / готовая аудиодорожка |

Длительность определяет, сколько материала покрывает фильм и размер всего пайплайна:

| Длительность | Кит. знаков | Англ. слов | Строк / шотов | Агентов-сборщиков | Время | Диск |
|---|---|---|---|---|---|---|
| 2–3 мин | 650–880 | 280–420 | 24–32 | 4–6 | ≈1 ч | ≈2 ГБ |
| 3–5 мин (эталон) | 1100–1400 | 420–700 | 40–50 | 8 | ≈2 ч | ≈2 ГБ |
| 5–8 мин | 1650–2200 | 700–1150 | 60–80 | 10–14 | ≈2–3 ч | ≈3 ГБ |

Число глав определяется содержанием в пределах, заданных длительностью: до 3 минут — одна глава (без карточек), 3–5 минут — 3–4 главы по ≥60 с, 5–8 минут — 4–6 глав. Прогресс-бар делится поровну по главам. Пустая строка в тексте означает абзац = один шот: предложения внутри абзаца разделены 10 кадрами, концы абзацев — 30, так что пауза приходится на смену картинки, и каждый шот держится 1–1,5 с после появления последнего элемента. Готовое видео по замыслу на 5–8 % длиннее чистой речи.

## Установка

```bash
git clone https://github.com/neuratechcompany-ops/Kettu-Shortmaster.git kettu-shortmaster
ln -s "$PWD/kettu-shortmaster" ~/.claude/skills/kettu-shortmaster   # Claude Code
ln -s "$PWD/kettu-shortmaster" ~/.codex/skills/kettu-shortmaster    # Codex
```

Зависимости:

```bash
# Node ≥18 (npm install шаблона тянет remotion 4.0.507 / react 19)
brew install ffmpeg          # извлечение кадров / перекодирование, обязательно

python3 -m venv ~/.venvs/a2e && source ~/.venvs/a2e/bin/activate
pip install 'edge-tts==7.2.8' numpy pillow scipy   # edge-tts нужно пинить: он следит за endpoint'ом Microsoft и ломается при обновлениях (с 7.2.0 границы слов надо запрашивать явно — скрипт это делает)

# только для английской озвучки (kokoro-82m работает локально)
pip install kokoro soundfile && brew install espeak-ng
```

`scipy` нужен только скрипту QC `frame_metrics.py`. Скрипты — zsh + Python 3, разработаны и проверены на macOS; Linux должен работать, Windows не тестировался.

### Linux / Raspberry Pi (ARM)

Проверено на Raspberry Pi 5 (ARM64, Python 3.13). Три отличия от macOS:

```bash
sudo apt install zsh espeak-ng                 # скрипты — #!/bin/zsh; espeak-ng для G2P kokoro/piper

# у Remotion нет headless-браузера под linux-arm64 → укажите системный Chromium:
sudo apt install chromium                       # или chromium-browser
export REMOTION_BROWSER_EXECUTABLE=/usr/bin/chromium   # читается template/remotion.config.ts (на macOS no-op)
```

**TTS на Linux/ARM.** `kokoro` (английский движок по умолчанию) трудно ставится на ARM/Python 3.13. Два локальных движка ставятся чисто — передаются через `TTS_ENGINE`:

```bash
# kokoro_onnx — естественный голос, onnxruntime (без torch/spaCy). Модель и голоса — из
#   github.com/thewh1teagle/kokoro-onnx releases (kokoro-v1.0.onnx, voices-v1.0.bin)
pip install kokoro-onnx
TTS_ENGINE=kokoro_onnx KOKORO_ONNX_MODEL=…/kokoro-v1.0.onnx KOKORO_ONNX_VOICES=…/voices-v1.0.bin \
  KOKORO_ONNX_VOICE=am_michael python3 scripts/tts_build.py

# piper — самый быстрый локальный, голос роботизированный; фолбэк для Pi. Голос .onnx — github.com/rhasspy/piper
pip install piper-tts
TTS_ENGINE=piper PIPER_MODEL=…/en_US-ryan-medium.onnx python3 scripts/tts_build.py
```

Движок `edge` (естественный, бесплатный, точный тайминг по границам слов) работает и на Linux без локальной модели — это облачный вызов Microsoft: `TTS_ENGINE=edge VOICE=ru-RU-DmitryNeural python3 scripts/tts_build.py`.

## Использование

В Claude Code или Codex просто скажите, что хотите. Скилл запускается сам:

> Сделай объясняющее видео про векторные базы данных.

> 讲一下向量数据库，做成一条讲解视频

Дальше он проходит 9 стадий из `SKILL.md`:

1. **Скаффолд** проекта Remotion из шаблона.
2. **Исследование** (1 агент): документ с источниками, каждый факт — с URL.
3. **Текст и таймлайн**: сценарий, затем TTS-озвучка с границами слов → покадровый таймлайн и таблица субтитров.
4. **Раскадровка**: по строке на шот с диапазоном кадров, битом, визуалом, движением, героем и светом.
5. **Оверлеи и примитивы**: титр, карточки глав, HUD, «труба» шагов, плюс 2–5 тематических иконок.
6. **Пилот** (1 агент): первая группа шотов, затем 30-секундный нарез для оценки вида.
7. **Параллельная сборка**: остальные группы, 5–7 шотов на агента, каждый пишет чистые Remotion-компоненты.
8. **Рендер** полного фильма и количественные метрики кадров.
9. **QC и правки**: по QC-агенту на главу, агенты-фиксы на группу, повторная проверка, затем заметки о сдаче.

Шаблоном можно управлять и вручную:

```bash
template/scripts/new_project.sh ~/work/my-video myslug
cd ~/work/my-video
# 1. research/调研.md          2. script/narration.txt → python3 scripts/tts_build.py
# 3. script/storyboard_src.md → python3 scripts/render_storyboard.py     4. правим src/config.ts
# 5. src/shots/G1..Gn          6. scripts/preview.sh 30   (первые 30 секунд)
# 7. VER=v1 scripts/render.sh + python3 scripts/frame_metrics.py         8. QC → фиксы → v2/v3
```

## Четыре контрольные точки

Прогон останавливается и ждёт вас ровно в четырёх местах (детали в `SKILL.md`):

1. **Длительность и язык**: до написания текста. Длительность задаёт число строк, шотов и сколько агентов работают параллельно; язык переключает `lang` в `src/config.ts`.
2. **Утверждение текста**: до озвучки. После фиксации номера кадров зашиты в каждый шот — изменение одного слова пересчитывает весь фильм. Это самое дешёвое место для вмешательства.
3. **Озвучка**: перед TTS вас спрашивают, есть ли предпочтительный движок. Если нет — дефолты (edge-tts Yunxi для китайского, kokoro-82m Liam для английского, edge-tts Dmitry для русского). Можно передать готовую аудиодорожку и заполнить таймлайн вручную.
4. **Первые 30 секунд**: собран только первый шот-группа, рендерится 30 секунд для оценки вида. Починить стиль здесь — один шот; после полного рендера — все.

## Чем отличается

| Класс инструмента | Что выдаёт | Где Kettu-Shortmaster другой |
|---|---|---|
| Генеративные видеомодели (Sora, Veo, Runway) | Кадры, синтезированные из промпта | Детерминированный код, а не пиксели. Каждое число на экране ссылается на источник, любой кадр чинится правкой одного файла шота |
| Аватар / диктор (HeyGen, Synthesia) | Цифровой ведущий читает сценарий | Нет ведущего. Motion-graphics схемы, показывающие механизм; текст ведёт визуал |
| Remotion / Motion Canvas вручную | Программируемый холст | Поверх холста — метод: исследование → текст → раскадровка → параллельная сборка → QC, со спецификациями стиля и эталонным фильмом |
| Manim | Python-анимации математики | End-to-end пайплайн с TTS-субтитрами, главами и QC; React / TypeScript вместо Python |

## FAQ

**С какими агентами работает?**
Написан для Claude Code и Codex, на них и прогонялся. Сам скилл — обычный Markdown плюс проект Remotion, так что любой агент, читающий папки `SKILL.md` и умеющий запускать shell, сможет следовать.

**Нужен ли GPU?**
Нет. Remotion рендерит через headless Chromium на CPU. Китайский и русский дефолтные голоса (edge-tts) — облачный вызов Microsoft; английский (kokoro-82m) — локальная модель на CPU.

**Можно ли свой голос или другой TTS?**
Да. Положите готовую аудиодорожку в `public/assets/<slug>/audio.wav` и заполните `src/common/timeline.ts` и `subs.ts` вручную (формат описан в шапке `tts_build.py`). Всё ниже по пайплайну не меняется.

**Можно ли сменить визуальный стиль?**
Стиль один, намеренно, с единственным переключателем — фон `bg` в `src/config.ts` (`'dots'` точечная волна по умолчанию, `'stars'` звёзды с туманом). Для остального правьте `reference/style-guide.md` и `src/ui.tsx`; код шотов использует только эти примитивы.

**Воспроизводимы ли рендеры?**
Да. Каждая анимация — чистая функция номера кадра с заданным сидом, ширина текста вычисляется, а не меряется в DOM, поэтому повторный рендер даёт идентичные кадры.

**Можно ли коммерчески?**
Инструментарий — по PolyForm Noncommercial: бесплатно для некоммерческого использования, коммерческое требует разрешения автора. Сделанные вами видео — ваши. См. [License](#license).

**Есть ли вертикаль (9:16)?**
Шаблон и все правила безопасных зон заточены под 1280×720 landscape. Вертикаль собирается отдельным форком (пример — «Машины благодатной любви» в `examples/lovinggrace/`).

**Какие языки?**
Китайский, английский и русский. У каждого своя модель пауз, бюджет субтитров и дефолтный голос.

## Оригинальность

- **Каждый кадр отрисован кодом.** Никаких кадров и клипов из существующих видео. Опциональный живой B-roll — только из royalty-free источников и с записью в MANIFEST (sha256 / URL источника / лицензия / использование).
- **Каждый факт имеет источник.** Каждое число, год, организация и термин на экране должны ссылаться на URL в исследовании фильма. Всё непроверенное не попадает ни на экран, ни в озвучку.

## Известные ограничения

- Поддерживаются китайский, английский и русский (`lang: 'zh' | 'en' | 'ru'`), у каждого свои паузы, бюджет субтитров и дефолтный голос. Один визуальный стиль с двумя фонами (`bg: 'stars' | 'dots'`); смена чего-то ещё — правка `reference/style-guide.md` + `src/ui.tsx`.
- Не для: копирования существующего видео, talking-head с ведущим, фильмов, где в основном живая съёмка.
- После озвучки слова заморожены — код шотов зашивает номера кадров, поэтому переписывание пересчитывает всё.
- Параллельная сборка требовательна: несколько агентов одновременно собирают Remotion, держите ≥5 ГБ свободно; панели tmux ограничены, после ~12 — запускайте волнами.
